# 制造交换 XML

Exchange 根节点声明 source、mapping；Transaction 提供 id、非负 sequence、含时区 at。两个命名空间 urn:manufacturing:1 与 urn:manufacturing:2 当前共享 Receive、Transform 语义，以显式版本分派，未知元素或属性不忽略。Receive 包含一个 Quantity；Transform 包含多个 Input/Output 和一个 Waste，各成员有 Quantity。数值为精确十进制，codes.json 定义外部物料、位置和单位换算。

receive.xml 是前序，transform.xml 可以先到；无前序时事务等待，不能创建无来源产出。对照表使用 id/revision 固定解释。样本通过直接文件采集进入适配器，原业务 events.consumer 保持顺序、依赖与守恒约束。解析器禁止外部实体，不向公网请求 DTD。

## 采集适配器（chainledger.events.manufacturing）

ManufacturingExchange 把每个 Transaction 整体转换为一个现有事件信封（一个 Transform 即一个 transform 操作），交由原 Consumer 消费链，不新增旁路写入：

- 解析：基于 expat，禁止 DOCTYPE、内部/外部实体声明、外部实体引用、记法与处理指令；仅接受两个已声明命名空间，未声明命名空间、未知元素或属性、非法十进制一律硬拒收（错误码 xml），不产生任何库写入。
- 对照表：mfg_mapping_load 加载 id/revision 版本化映射；同一 id+revision 内容不可变，新版本以更大 revision 声明。单位按精确十进制 factor 换算，Transform 全部成员必须落到同一规范单位，否则 unit_mismatch。
- 整事务原子性：任一成员的物料、位置、单位无法转换时，整个事务停在适配器 blocked 状态，不提交任何投入或产出；损耗数量原样传递，守恒由原 graph 校验，不补平。
- 引用与重试：批次或跨文件前序未解决时，信封进入原 Consumer 的 pending/blocked，前序到达后 drain 自动重试；mfg_unresolved 统一查询未应用事务。
- 证据留存：mfg_transactions 保存外部事务号、源序号、XML 位置（含起始行号）、映射 id/revision/digest 与内容摘要；已接受事务钉在转换时的映射版本，新映射不会改变其解释。
- 幂等与隔离：按文件 SHA-256 去重，重复文件不改变物料图；同 source+外部事务号但内容不同的变更进入 mfg_quarantine 隔离，不覆盖原事务。
- 可修复重处理：mfg_reprocess 仅允许重处理适配器 blocked 事务；操作员补齐对照表后重跑选定事务，仍失败则保留新原因，成功才提交信封。

动作：mfg_mapping_load、mfg_mappings、mfg_ingest、mfg_reprocess、mfg_transactions、mfg_transaction、mfg_unresolved、mfg_quarantine。

## 端到端演练

demo_support/mfg_drill.py 以独立临时数据库、隔离模式（python -I）运行，输入位于 demo_support/mfg_drill（交换文件）与 demo_support/mfg_maps（对照表修订），覆盖跨文件前序与同文件后向批次、g→kg 单位换算、成员级整事务拒收、不守恒拒收、未知代码补齐重试、重复文件幂等、同号异内容隔离、外部实体/未声明命名空间/未知结构硬拒收，并以现有审计链、守恒报告与谱系拓扑核对结果。
